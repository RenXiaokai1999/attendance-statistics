# attendance-statistics

面向大同地震监测中心站的月度考勤统计系统，以 Codex/Claude Skill 形式运行。

## 主要功能

- 下载并解析整月签卡记录，按“当天有打卡即出勤”统计出勤天数。
- 汇总 24 小时值班零报告和周末数据预处理值班记录。
- 识别企业微信图片中的调休、请假、因公外出和用车申请。
- 所有正式用车申请先纳入“因公外出”，写入明细表，供人工最终甄别。
- 生成旧版 `.doc` 考勤表和带状态底色的 `.xlsx` 签卡记录副本。
- 输出冲突、资料缺失和低置信度事项，支持补齐资料后手动重跑。

## 安全设计

- 网站账号和密码仅保存在 Windows 凭据管理器，不写入代码或配置文件。
- 原始签卡、人员考勤结果、企业微信图片和本地运行工作区不纳入版本库。
- Word 模板和源数据只读，所有结果另存生成。

## 使用方式

将本仓库作为 `attendance-statistics` Skill 安装到用户级 Skill 目录，按实际环境修改 `config/settings.json` 中的路径，并先运行：

```powershell
python scripts/setup_credentials.py
```

随后可通过“统计上月考勤”“生成某月考勤表”或“重跑某月考勤”等请求触发。

详细统计规则见 [SKILL.md](SKILL.md) 和 `references/` 目录。
