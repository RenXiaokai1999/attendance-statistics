# 考勤统计 Skill 设计

## 1. 目标

构建一个本地 Codex Skill，在每月1日15:00统计上一个自然月的考勤，生成旧版 Word 考勤汇总表和带每日状态颜色的 Excel 签卡记录。任务同时支持用户补齐资料后的手动重跑。

## 2. 推荐实现

采用“Skill 编排＋确定性脚本”：Skill 负责月份计算、流程控制、异常决策和结果说明；脚本负责网页登录下载、结构化文件解析、图片识别、Word 写入和 Excel 着色。

相比纯提示词执行，该方案更容易稳定复现、测试和维护；相比单一固定 RPA，又能保留图片不确定性判断和人工复核能力。

## 3. 数据流

1. 计算目标月份和起止日期。
2. 检查凭据、模板及两个手动资料目录。
3. 登录汇顺云考勤平台，下载上月签卡记录到当月目录。
4. 从签卡记录统计出勤天数。
5. 从每日零报告统计全日班。
6. 从数据预处理 HTML 分页统计符合条件的周末白班。
7. 从目标月及前一个月图片中统计获批补休、请假和因公外出。
8. 将全部记录规范化为“姓名、日期、类型、来源、审批状态”。
9. 去重、处理撤回和改期、检测冲突及不确定项。
10. 写入另存的 Word `.doc` 考勤表。
11. 生成另存的 Excel 考勤标注表。
12. 验证输出并报告统计结果和待确认事项。

## 4. 输入与输出

### 输入

- 汇顺云上月签卡记录 `.xlsx`。
- `24h值班和预处理\YYYYMM\24h值班` 中每日 `.doc` 零报告。
- `24h值班和预处理\YYYYMM\数据预处理\YYYY\M月` 中 HTML 页面及配套分页。
- 企业微信图片缓存中 `YYYY-MM` 与前一个月两个目录。
- 固定 Word `.doc` 模板。
- 国家当年度放假及调休工作日安排。

### 输出

- `考勤\YYYY年M月\YYYYMMDTZ考勤表.doc`
- `考勤\YYYY年M月\签卡记录YYYY-MM-01到YYYY-MM-月末_考勤标注.xlsx`
- 运行摘要及异常、冲突、未审批、待人工确认清单。

## 5. 统计规则

### 出勤

同一人员当天存在任意打卡记录即计1天，多次打卡不重复累计。

### 全日班

每日异常零报告末尾“填报人”计1次。同日不同填报人冲突时不计。

### 白班

从 HTML 表格读取日期和值班员。仅统计正常休息性质的周六、周日；法定节假日内周末及调休上班周末均不计。同日不同值班员冲突时不计。

### 补休

只统计已获确认且实际调休日期属于目标月份的记录。按人员和日期去重。未批准申请只提醒，不计入。

### 请假

统计已批准的年假、育儿假、探亲假及其他非调休休假。跨月只计目标月份。图片未给明确天数时按国家工作日计算；半天和按小时记录暂不计。

### 因公外出

统计已批准的出差、水准测量，以及事由明确为出差或水准测量的用车附件。符合条件的附件中所有使用人分别计入，其他用车附件不计。按国家工作日计算，半天和按小时记录暂不计。

## 6. Word 处理

模板为旧版 OLE `.doc`，通过本机 Microsoft Word 自动化读取和保存，以保持格式不变。主表按姓名定位，写入出勤、因公外出、请假、全日班、白班和补休列。模板外人员追加到末尾，其他项目留空。无统计值的单元格保持空白。

## 7. Excel 着色

按姓名行和日期列定位单元格，保留现有打卡时间：

- 有打卡：无底色；
- 无打卡但有全日班或白班：无底色；
- 因公外出：`#002060`；
- 补休：`#92D050`；
- 请假：`#000000`；
- 缺卡且无有效状态：`#FF0000`；
- 多个互斥状态：不着色并报告；
- 有打卡与休假或外出状态并存：无底色并报告。

着色结果另存为 `_考勤标注.xlsx`，不覆盖原始下载文件。

## 8. 安全与失败处理

登录信息保存于 Windows 凭据管理器，Skill 和任务只引用凭据名称。日志不得包含账号、密码或会话信息。

缺少任何手动资料目录、登录失败或下载失败时立即停止。单个文件异常不阻塞其他文件处理，但必须进入最终清单。自动任务失败后不自动重试，由用户补齐后手动触发。

## 9. 测试

1. 使用2026年8月真实资料在独立测试目录进行端到端测试。
2. 模拟缺少手动目录，验证安全中止。
3. 测试重复、未审批、跨月、半天、同日冲突、新人员、节假日和调休工作日等边界。

## 10. 验收

- 原始文件哈希不变。
- Word `.doc` 可正常打开且版式未损坏。
- 六项统计与抽样人工核对一致。
- Excel 打卡时间不变，颜色规则准确。
- 所有不确定项均显式报告。
- Skill、日志和定时任务中无明文凭据。
