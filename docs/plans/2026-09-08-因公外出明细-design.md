# 因公外出规则扩展与明细登记设计

## 目标

扩展月度考勤中“因公外出”的识别范围，并把与第一张统计表口径完全一致的已批准记录写入第二张“因公外出、请（休）假和缺勤情况登记表”。

## 业务口径

- 因公外出包括：因公出差、因公外出办事、经组织同意参加学习培训。
- 水准测量按“因公外出办事”处理。
- 用车附件仍只统计明确属于因公出差或水准测量的记录；其他办事、培训用车附件不作为统计依据。
- 只统计明确获批、属于目标月份且按工作日日历计算后有效的整天记录。
- 未获批、半天或小时、信息不清及互斥冲突记录不填写，进入人工确认清单。

## 明细表写入方式

采用“每个已批准事项一行”。生成当月文件时，清空第二张表除表头外的模板示例行，再写入目标月份明细；行数不足时自动追加。

| 列 | 写入内容 |
|---|---|
| 登记时间 | 事项开始日期，格式 `M.d` |
| 登记人 | 申请人或主要登记人 |
| 类别 | 固定填写“因公外出” |
| 因公外出或请假事由及地点 | 具体事由和地点；有可靠信息时如实填写 |
| 起止时间、天数 | 起止日期及目标月内有效工作日天数 |
| 外出或请休假批准人 | 图片中能明确识别的批准人；无法确认则留空 |
| 备注 | 同行人员、培训组织单位等补充信息 |

同一事项有多名人员时，申请人填“登记人”，其余人员写入“备注”的同行人员；第一张表仍为所有参加人员分别累计有效工作日。

## 数据一致性

- 第二张表只使用归并后最终生效的因公外出记录，不直接使用未经确认的 OCR 候选。
- 第一张表“因公外出（天）”、Excel 深蓝色状态与第二张明细来自同一批最终记录。
- 同一来源、事项和日期范围只写一条明细，避免按人员展开造成重复。

## 验证

- 分类测试覆盖三类因公外出、水准测量和用车附件边界。
- Word 测试验证模板示例已清空、明细列映射正确、同行人员不重复成行、行数可扩展。
- 流水线测试验证第一张表累计天数和第二张表明细使用同一批记录。
- 重新打开生成的旧版 `.doc`，核对两张表及文件格式。
