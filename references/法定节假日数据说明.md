# 法定节假日数据说明

年度日历保存为 `references/workdays/YYYY.json`，必须来自国务院办公厅当年放假安排通知，并人工核对后使用。

```json
{
  "year": 2026,
  "source": "官方通知网址",
  "holidays": ["2026-01-01"],
  "adjusted_workdays": ["2026-01-04"]
}
```

- `holidays`：法定放假安排中的全部休息日期，包括落在周六、周日的节假日。
- `adjusted_workdays`：因调休而正常上班的周六、周日。
- 普通周一至周五视为工作日，普通周六、周日视为休息日。
- 文件缺失、年份不匹配或日期跨年时立即停止，不能猜测。
