# 图片分类规则

- 调休：必须同时识别到“调休”和确认词“同意 / 批准 / 收到”。只有申请没有确认时列入提醒。
- 请假：识别“山西省地震局 请休假审批单”、请假、年假、育儿假、探亲假、婚假、病假、事假等；调休不归入请假。
- 因公外出：识别因公出差、因公外出办事，以及经组织同意参加学习培训；“水准测量”“水准观测”“水准作业”“水准观测记录手簿”均归入因公外出办事。
- 正式用车单据：识别“用车申请”“用车审批单”“派车申请”等；无论事由、审批状态以及是否撤回、取消、作废，均标记为正式用车申请并进入因公外出统计。
- 正式用车单据优先级最高；即使文字中同时出现出租车、打车或网约车，也按正式用车申请统计。只有票据、没有正式申请单时才执行即时客运排除。
- 视觉复核时记录申请人和全部明确使用人；汇总分别计数，第二张表按一个事项一行填写，其他使用人写入同行人员。
- 租车：识别“租车”“车辆租赁”“汽车租赁”等材料。只要日期和人员明确即可作为因公外出依据，不要求另有审批截图。
- 租车材料只有承租人时只计承租人，不推测同行人员；日期或人员不清时进入人工确认。
- 同一租车事项的合同、发票、订单和明细按事项、人员、日期归并去重。
- 即时客运排除：单独“出租车”“打车”“网约车”票据不统计；正式用车申请不受此排除限制。
- 单独附件未出现正式用车申请时，租车材料按独立证据规则处理，其他普通用车附件不自动统计。
- 复核因公外出时同时记录事项标识、申请人、参加人员、事由、地点、批准人和原始起止日期，供 Word 明细表去重填写。
- 撤回 / 撤销 / 取消 / 作废：作为后续版本处理，不直接计数。
- 半天 / 半日 / 小时：列入人工判断，不自动填写。
- 同一图片命中多个类别、姓名或日期识别不清、审批状态不清时，必须人工复核。
- OCR 同时采用整块文本和稀疏文本两种版面模式合并结果；横置且首次未分类的图片再旋转90度、270度复查。只按文件内容完全相同去重，不用感知哈希删除近似图片。
- OCR 只负责筛选候选，最终结构化记录需由 Skill 视觉核对原图。
